## 1. 메인 레이아웃 (Main Layout)

**관련:** US-01, US-02, US-03 | F-01~F-04, F-10~F-15, F-60~F-62

앱 기동 시 기본 화면. 3-패널 구성: 사이드바, 콘텐츠 영역(터미널/파일), 채팅 패널.
리사이즈 경계(`║`)로 각 영역 폭 조절 가능.

```

│  ← 드래그 가능 타이틀바 (frameless) →                                    │
├──────────║──────────────────────────────────────║────────────────────────┤
│ SIDEBAR  ║  CONTENT AREA                       ║  CHAT PANEL            │
│ 240px    ║  (flex: 1)                          ║  320px                 │
│          ║                                     ║                        │
│ ┌──────┐ ║  ┌─────┬─────┬─────┬───┐           ║  ┌────────────────────┐│
│ │AGENTS│ ║  │ FE  │ BE  │ Inf │ + │  Tab Bar   ║  │  TEAM CHAT         ││
│ ├──────┤ ║  ├─────┴─────┴─────┴───┤           ║  │                    ││
│ │      │ ║  │                     │           ║  │  [Avatar] Agent1   ││
│ │ (*)FE│ ║  │                     │           ║  │  메시지 내용...     ││
│ │      │ ║  │                     │           ║  │                    ││
│ │ (*)BE│ ║  │    xterm.js         │           ║  │  [Avatar] @BE      ││
│ │      │ ║  │    Terminal         │           ║  │  코드 블록 + 파일   ││
│ │ ( )IF│ ║  │                     │           ║  │  참조 링크          ││
│ │      │ ║  │                     │           ║  │                    ││
│ ├──────┤ ║  │                     │           ║  │  [Avatar] Human    ││
│ │[+Add]│ ║  │                     │           ║  │  지시 메시지...     ││
│ ├──────┤ ║  │                     │           ║  │                    ││
│ │STATUS│ ║  │                     │           ║  ├────────────────────┤│
│ │      │ ║  │                     │           ║  │  @ mention input   ││
│ │Token:│ ║  └─────────────────────┘           ║  │  [파일] [Send >>>] ││
│ │ 12.3k│ ║                                     ║  └────────────────────┘│
│ │      │ ║  ┌─────────────────────┐           ║                        │
│ │Alerts│ ║  │ (승인 배너 영역)    │           ║  ┌────────────────────┐│
│ │[!] 2 │ ║  │ [승인] [거부] [전체]│           ║  │ FILE PREVIEW       ││
│ └──────┘ ║  └─────────────────────┘           ║  │ (조건부 표시)      ││
│          ║                                     ║  │ 코드/마크다운 렌더 ││

**레이아웃 규격:**

| Content Area | flex: 1 | 400px | -- | 자동 |
| Chat Panel | 320px | 280px | 480px | 좌우 드래그 |

## 10. 키보드 단축키 요약

| 단축키 | 동작 |
|--------|------|
| `Cmd+1~9` | 에이전트 탭 전환 |
| `Cmd+P` | Quick Open (파일 검색) |
| `Cmd+Shift+C` | 채팅 패널 토글 |
| `Cmd+Shift+F` | 파일 뷰어 토글 |
| `Cmd+Shift+K` | Kill All (긴급 정지) |
| `Cmd+Enter` | 메시지 전송 (채팅 입력) |
| `@` + typing | 에이전트 멘션 자동완성 |
| `Cmd+,` | 설정 열기 |
| `Cmd+Shift+A` | 승인 대시보드 열기 |

## 가정 사항

1. 타이틀바는 Electron frameless window + 커스텀 드래그 영역으로 구현
2. 다크 테마를 기본으로 하되, 라이트 테마 지원은 v1.1에서 구현
3. 채팅 패널은 사이드 패널 모드(기본)와 전체 화면 모드를 지원
4. 파일 뷰어의 코드 편집은 지원하지 않음 (읽기 전용)
5. 반응형 레이아웃은 최소 1280x720 해상도를 기준으로 설계
