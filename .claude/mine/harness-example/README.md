# Harness Example Prompts

하네스 스킬(`/harness`)을 트리거하기 위한 예시 프롬프트 모음.
각 파일에는 기본 프롬프트 + 구체적 변형 3가지 + 예상 아키텍처가 포함되어 있다.

## 사용법

1. 아래 프롬프트를 Claude Code에 입력하면 `/harness` 스킬이 자동 트리거됨
2. 기본 프롬프트는 범용, 변형 프롬프트는 특정 도메인에 맞춤
3. 예상 아키텍처는 참고용 — 실제 하네스 구성은 스킬이 자동 설계

## 하네스 아키텍처 패턴 요약

- **팬아웃/팬인**: 병렬 독립 작업 → 결과 통합 (리서치, 코드 리뷰)
- **파이프라인**: 순차 의존 작업 (문서 생성, 웹사이트 개발)
- **계층적 위임**: 상위→하위 재귀적 위임 (데이터 파이프라인)
