# 종합 코드 리뷰 하네스 — 예시 프롬프트

## 기본 프롬프트

```
종합 코드 리뷰 하네스를 구성해줘. 아키텍처, 보안 취약점, 성능 병목, 코드 스타일을
병렬로 감사하는 에이전트들이 결과를 하나의 리포트로 통합하는 팀.
```

## 구체적 변형 프롬프트

### PR 기반 리뷰
```
이 PR의 변경사항을 종합 코드 리뷰해줘.
보안 리뷰어가 취약점을 점검하고, 성능 리뷰어가 병목을 분석하고,
테스트 리뷰어가 커버리지를 검증하는 팀을 돌려줘.
리뷰어들이 서로 발견을 공유하면서 교차 영역 이슈도 포착해야 해.
```

### 레거시 코드 감사
```
src/ 디렉토리 전체를 대상으로 종합 코드 감사를 해줘.
아키텍처(의존성 방향, 레이어 위반), 보안(SQL 인젝션, XSS, 인증 누락),
성능(N+1 쿼리, 메모리 누수), 코드 스타일(일관성, 네이밍) 4개 관점에서
병렬 감사 후 하나의 리포트로 통합해줘. 심각도별 정렬 필수.
```

### 마이그레이션 전 검증
```
TypeScript 5.x 마이그레이션 전에 코드베이스를 검토해줘.
타입 호환성, deprecated API 사용, 성능 영향, 테스트 깨짐 위험을
각각 전문 리뷰어가 점검하고, 마이그레이션 리스크 리포트를 만들어줘.
```

## 예상 아키텍처

- **패턴**: 팬아웃/팬인 + 토론
- **실행 모드**: 에이전트 팀
- **팀 구성**: security-reviewer, performance-reviewer, test-reviewer, (architecture-reviewer) + 리더(통합)
- **핵심**: 리뷰어 간 SendMessage로 교차 영역 이슈 공유 (예: 보안→성능 "이 쿼리 인젝션 가능, 성능도 확인 필요")
- **산출물**: 관점별 개별 리뷰 + 통합 리포트 (심각도별 정렬, 교차 영역 이슈 하이라이트)
