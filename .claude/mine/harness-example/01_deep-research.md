# 딥 리서치 하네스 — 예시 프롬프트

## 기본 프롬프트

```
리서치 하네스를 구성해줘. 어떤 주제든 여러 각도에서 조사할 수 있는 에이전트 팀이
필요해 — 웹 검색, 학술 자료, 커뮤니티 반응 — 교차 검증 후 종합 보고서를 작성하는 팀.
```

## 구체적 변형 프롬프트

### 기술 트렌드 조사
```
"2026년 AI 에이전트 프레임워크 비교" 주제로 딥 리서치 해줘.
공식 문서, 벤치마크, GitHub 이슈, 커뮤니티 의견을 교차 검증해서
종합 보고서로 만들어줘.
```

### 시장 조사
```
"한국 SaaS 시장의 AI 도입 현황"을 조사해줘.
투자 동향, 언론 보도, 개발자 커뮤니티 반응, 학술 자료를 수집하고
상충되는 데이터는 출처를 병기해서 보고서로 정리해줘.
```

### 경쟁사 분석
```
Cursor, Windsurf, Claude Code의 AI 코딩 도구 비교 리서치를 해줘.
공식 기능 목록, 사용자 리뷰, 벤치마크, 가격 정책을 각각 조사하고
교차 검증해서 비교표와 종합 분석을 만들어줘.
```

## 예상 아키텍처

- **패턴**: 팬아웃/팬인
- **실행 모드**: 에이전트 팀
- **팀 구성**: 공식채널 연구원, 미디어 연구원, 커뮤니티 연구원, 배경 연구원 + 리더(통합)
- **핵심 도구**: WebSearch, WebFetch, SendMessage, TaskCreate
- **산출물**: `_workspace/` 하위 개별 보고서 + 최종 종합 보고서
