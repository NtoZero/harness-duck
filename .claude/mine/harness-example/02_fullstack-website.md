# 풀스택 웹사이트 개발 하네스 — 예시 프롬프트

## 기본 프롬프트

```
풀스택 웹사이트 개발 하네스를 구성해줘. 디자인, 프론트엔드(React/Next.js),
백엔드(API), QA 테스트를 와이어프레임부터 배포까지 파이프라인으로 조율하는 팀.
```

## 구체적 변형 프롬프트

### SaaS 대시보드
```
SaaS 관리자 대시보드를 만들고 싶어. Next.js + Tailwind 프론트엔드,
Express + Prisma 백엔드, PostgreSQL DB 구조.
와이어프레임 → 컴포넌트 개발 → API 구현 → 통합 테스트까지
파이프라인으로 진행하는 풀스택 하네스를 구성해줘.
```

### 랜딩 페이지 + API
```
제품 랜딩 페이지와 대기자 등록 API를 만들 건데,
디자인 시스템 정의 → 프론트엔드 구현 → API 개발 → QA까지
한 팀이 조율하는 하네스를 구성해줘. 기술 스택은 React + Hono.
```

### 모노레포 멀티 서비스
```
이 모노레포에서 프론트엔드(/apps/web), 백엔드(/apps/api),
공유 라이브러리(/packages/shared)를 동시에 개발하는 하네스를 구성해줘.
API 스펙 변경 시 프론트/백이 자동으로 동기화하고,
QA가 경계면을 교차 검증하는 팀이 필요해.
```

## 예상 아키텍처

- **패턴**: 파이프라인 + 팬아웃 (Phase별 팀 재구성)
- **실행 모드**: 에이전트 팀
- **팀 구성 (Phase별)**:
  - Phase 1: designer (와이어프레임/디자인 시스템)
  - Phase 2: frontend-dev + backend-dev (병렬 개발, SendMessage로 API 스펙 동기화)
  - Phase 3: qa-engineer (경계면 교차 검증)
- **핵심**: 프론트/백 에이전트 간 API 계약 실시간 공유, QA의 경계면 비교
- **산출물**: 실행 가능한 코드 + QA 리포트
