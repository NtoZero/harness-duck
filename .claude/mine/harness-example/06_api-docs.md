# 기술 문서 자동 생성 하네스 — 예시 프롬프트

## 기본 프롬프트

```
이 코드베이스에서 API 문서를 자동 생성하는 하네스를 구성해줘. 엔드포인트 분석,
설명 작성, 사용 예제 생성, 완성도 리뷰를 파이프라인으로 처리하는 팀.
```

## 구체적 변형 프롬프트

### REST API 문서화
```
src/api/ 디렉토리의 모든 REST 엔드포인트를 분석해서 API 문서를 생성해줘.
1단계: 엔드포인트 스캔 및 분류
2단계: 각 엔드포인트의 요청/응답 스키마 추출 + 설명 작성
3단계: curl/fetch 사용 예제 생성
4단계: 완성도 리뷰 (누락 필드, 에러 응답, 인증 요구사항 점검)
이 파이프라인을 하네스로 구성해줘.
```

### SDK 레퍼런스 문서
```
packages/sdk/ 의 공개 API를 문서화하는 하네스를 구성해줘.
타입 분석기가 export된 함수/클래스를 추출하고,
문서 작성자가 JSDoc 기반으로 설명을 작성하고,
예제 생성기가 실행 가능한 코드 예제를 만들고,
리뷰어가 정확성과 완성도를 검증하는 팀.
```

### 변경 로그 자동 생성
```
최근 20개 커밋의 변경사항을 분석해서 릴리스 노트를 작성하는 하네스를 구성해줘.
커밋 분석기가 변경 유형을 분류하고, 문서 작성자가 사용자 관점 설명을 쓰고,
리뷰어가 누락된 breaking change나 마이그레이션 가이드를 점검하는 팀.
```

## 예상 아키텍처

- **패턴**: 파이프라인
- **실행 모드**: 에이전트 팀 (Phase별 팀 재구성) 또는 서브 에이전트 (순차 호출)
- **팀 구성**: endpoint-analyzer, doc-writer, example-generator, completeness-reviewer
- **핵심**: 분석기가 코드에서 추출한 구조화 데이터를 파일 기반으로 다음 단계에 전달
- **산출물**: OpenAPI 스펙 / 마크다운 API 문서 + 사용 예제 + 완성도 리포트
